# 持ち越し（今後の改善）

ここに書くのは「いまは直さないと決めたもの」だけです。直したものはここから消し、決めた理由を残します。

## テスト：修正ガイドの網羅性の確かめ方（LOW・0.2.0 のレビューで指摘）

- **現状**：`test/fix-guide.test.ts` の「🔴・🟠 になりうる項目のすべてに直し方がある」は、`src/checks/build.ts` のソースを文字列として読み、`id: '…'` の直後の `status: 'danger' | 'warn'` を正規表現で拾って、対象の項目（0.2.0 時点で固定の13種類と、サービスごとの秘密情報）を集めています。
- **弱いところ**：項目の書き方（`id` と `status` の並び・改行）を変えると、正規表現が拾えなくなり、対象から漏れても気づきにくい。件数の下限（11件以上）と、定義の取り残しの確認で一部は止まるが、完全ではない。
- **いま直さない理由**：0.2.0 の時点では、すべての 🔴・🟠 の項目に直し方があることを、この確認と、実際のフォルダを使った確認（`messyProject`）・実機の確認で確かめられている。テスト基盤を大きく変える必要はない。
- **直すなら**：`src/checks/build.ts` の 🔴・🟠 の項目のIDを、コードの中の一覧（定数）として持ち、`buildChecks` とテストの両方がその一覧を使う。あるいは、すべての項目を出すフィクスチャを用意し、実際に `buildChecks` を通して確かめる。

## 秘密鍵の構造の確かめ方：DER・PGP・PuTTY の検証が浅い（MEDIUM・0.2.0 の最終レビューで指摘）

- **現状**：`src/detect/key-structure.ts` は、PKCS#1・PKCS#8・EC・DSA を「外側の SEQUENCE の長さがちょうど全体で、中の要素を最後まで読めること」で、PGP を「最初のパケットが秘密鍵（タグ 5）で、CRC-24 が合うこと（チェックサムがある場合）」で、PuTTY を「秘密の部分が十分な長さのランダムな中身であること」で確かめている。どれも中身のランダムさの確認と組み合わせている。
- **弱いところ**：DER は中の要素の種類・順番（INTEGER の並び・OID など）までは見ていない。PGP はパケットの長さ・中身の形、PuTTY は MAC や鍵の種類ごとの長さを見ていない。手で作った「それらしい形のダミー」を本物と数える余地がある（誤検出の方向。見逃しの方向ではない）。
- **いま直さない理由**：0.2.0 の公開前の修正は HIGH に限ったため。本物の鍵を見逃さないこと（0.2.0 の修正の目的）は、実際の鍵での確認で満たしている。
- **直すなら**：PKCS#1・PKCS#8・SEC1 ごとに、決まった要素の並び（バージョンの INTEGER・アルゴリズムの OID など）を確かめる。PGP はパケットの長さの読み取り、PuTTY は鍵の種類ごとの長さの範囲を確かめる。誤検出が減ることを、見本のダミーと実際の鍵の両方で確かめる。

## ドキュメント：昔の設計の文書に、秘密鍵の古い判定の説明が残っている（LOW・0.2.0 の最終レビューで指摘）

- **いま直さない理由**：工程の記録は、その時点の設計の記録として残している。0.2.0 の判定は CHANGELOG とコードの説明に書いた。
- **直すなら**：工程の記録の該当箇所に「0.2.0 で、鍵の構造で判定する方式に変えた（CHANGELOG を参照）」という注記を足す（記録の本文は書き換えない）。

## 直したもの

- **秘密鍵の判定（鍵の本体に test などの語が偶然含まれると見逃す）**：0.2.0 で、語ではなく鍵の構造で判定するように直した（CHANGELOG の 0.2.0 を参照）。
- **コードの中で文字列を連結して書いた鍵の取り出し（HIGH・0.2.0 の最終レビューで指摘）**：連結の `+` と base64 の `+` を取り違えて本体を壊し、本物の鍵を 🟠 に下げていた。引用符の内側だけをつなぐように直した（CHANGELOG の 0.2.0 を参照）。
- **名前つきの秘密鍵が最終的な結果から消える（HIGH・0.2.0 の最終レビューで指摘）**：変数名があるだけで、同じファイルの秘密鍵の項目を出さなかった。同じ鍵を指すときだけ重ねて出さず、重いほうを残すように直した。1つのファイルの複数の鍵も、それぞれ数える（CHANGELOG の 0.2.0 を参照）。
- **変数の断片から組み立てた鍵を見逃す（HIGH・0.2.0 の最終レビューで指摘）**：同じファイルの文字列の定数を、実行せずに読んで復元するようにした。復元できない部分がある鍵は 🟠 にする（CHANGELOG の 0.2.0 を参照）。
