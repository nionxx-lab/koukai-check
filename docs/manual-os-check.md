# OS・端末ごとの手動確認チェックリスト

開発に使ったクラウド環境は Linux（Node 22 / 24）だけで、本物の端末（TTY）も使えませんでした。
そのため、**トークンを非表示で入力できること**と**ブラウザの自動起動**は、各OSで人が確認する必要があります。

各環境で、次の A〜H を確認してください。トークンは**テスト用**のもの（確認後に削除するもの）を使います。

| 記号 | 確認すること | 期待する結果 |
|---|---|---|
| A | トークンを**貼り付け**て Enter | 画面に何も表示されない（`*` も出ない）。カーソルも動かない |
| B | トークンを途中まで**手で入力**し、Backspace で数文字消してから続きを入力して Enter | 何も表示されない。正しいトークンとして受け付けられる（401にならない） |
| C | 日本語IMEを**オン**にしたまま、トークンを貼り付ける | 何も表示されない。全角になっても受け付けられる |
| D | 日本語IMEを**オン**にしたまま手で入力する | IMEの変換窓に文字が出る**ことがある**（既知の制約。案内文で「IMEはオフにして貼り付けて」と案内している）。結果を記録する |
| E | トークン入力中に Ctrl+C | 「中断しました。」と表示されて終了する。その後、端末で普通に文字を入力できる（表示されなくならない） |
| F | 診断後、ブラウザが自動で開く | 既定のブラウザでレポートが開く。開かない場合は URL が表示され、手で開ける |
| G | レポートで「AIに修正を頼む指示をコピー」 | 「コピーしました」と表示され、貼り付けられる |
| H | ターミナルの日本語・絵文字（🔴🟠🔵） | 文字化けしない（絵文字が四角になる場合は記録する） |
| I | レポート表示中に Ctrl+C | 「終了しました。」と表示されて終了する |

Windows で追加で確認すること：
- [ ] ブラウザの起動（`cmd /c start "" <URL>`）で、余分なウィンドウが残らない

- [ ] パスに日本語や空白を含むフォルダで `npx` を実行しても動く
- [ ] `--from-file` に `C:\Users\…\result.json` のようなパスを渡せる
