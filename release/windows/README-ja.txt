公開前チェック（Windows 版） koukai-check 0.1.0

■ 使い方
1. koukai-check-0.1.0-win-x64.exe をダブルクリックします。
   （Node.js などのインストールは必要ありません）
2. 「公開前チェック」のウィンドウが開きます。
   （黒い画面やブラウザは開きません）
3. 「チェックするアプリのフォルダを選ぶ」を押して、アプリのフォルダを選びます。
4. 使い終わったら、画面の「終了する」を押すか、ウィンドウ右上の × で閉じます。

■ 「Windows によって PC が保護されました」と表示された場合
このツールには、まだ発行元の電子署名がありません。そのため、初めて実行するときに
この画面が表示されることがあります。
「詳細情報」を押し、アプリ名を確認してから「実行」を押してください。

■ 「WebView2 ランタイムが見つかりませんでした」と表示された場合
画面の表示に、Windows の部品「Microsoft Edge WebView2 ランタイム」を使います。
Windows 11 には最初から入っています。Windows 10 で表示された場合は、案内に従って
Microsoft の公式ページから「Evergreen ブートストラップ」をインストールしてください。

■ プライバシー・通信
・通常のローカル診断（フォルダのチェック）では、診断するアプリのソースコード・認証情報・
  診断結果を作者のサーバーへ送信しません。作者のサーバー自体を使っていません。
・チェックと画面の表示は、このPCの中（127.0.0.1）で行われます。
・Supabase の診断を選び、確認の画面で「接続して診断する」を押して実行した場合にだけ、
  Supabase 公式API（api.supabase.com）へ接続します。アクセストークンは保存しません。
・画面の表示に使う Windows の部品「Microsoft Edge WebView2」は、Windows の設定に従って
  Microsoft と通信することがあります（更新・診断データなど）。これは Windows 側の動きです。
  koukai-check 自身には、診断するファイルや診断結果を Microsoft へ送る処理はありません。
・フォルダの中身を書き換えることはありません。
・初回の起動時に、画面の部品を次の場所に置きます（診断結果は保存しません）。
    %LOCALAPPDATA%\koukai-check\
  使わなくなったら、このフォルダごと削除してかまいません。

■ ファイルの確認（任意）
同じフォルダの SHA256SUMS.txt に、exe の SHA256 を記載しています。
PowerShell で次のように確認できます。
  Get-FileHash .\koukai-check-0.1.0-win-x64.exe -Algorithm SHA256
